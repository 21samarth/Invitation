# Page topology: shrushti-pritesh.ai.studio

The supplied target is a single invitation page. It opens on a full-screen
envelope cover, then switches to a vertically scrolling invitation containing:

1. Couple/ceremony hero
2. Scratch-to-reveal countdown
3. Eight-card events schedule
4. Attendance message
5. Family messages
6. Venue and directions link
7. Footer

Persistent layers are falling floral/butterfly decoration and a music toggle.
The source export is retained verbatim as the rendering implementation so these
sections, their responsive rules, and their interaction model remain identical.
